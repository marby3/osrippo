# 答弁イベントの質問と答弁（記録）

Issue #181。受入基準は Issue #181、前提の決定は Issue #147 の決めること14（2026-11-10 ユーザーと決定）。告知と一覧は #153（[153.md](153.md)）。

## 決めたこと

- 質問は1つの回に1人1件、400字まで（質疑の質問と同じ）。登録から7日と Turnstile が要る。書いたあとは直せず、消せない（質疑と同じ）
- 議員は、ほかの議員の回にも質問を書けない（決めること4の「答弁イベント」は、告知と答弁を指すと読む）。質問のあとで議員になった人の質問は残す
- 「わたしも聞きたい」の回数の上限は「わかる」と同じ数（24時間に50回、短いあいだに10回、同じ回線から1つの質問に3アカウントまで）。数えるのは「わたしも聞きたい」の付け外しだけで、「わかる」とは別に数える（「わかる」を数える表 `actions` の種類には CHECK があり、種類を足すと表の作り直しになるため、別の表 `toben_want_logs` に記録する）
- 「わたしも聞きたい」を外すのは、付けたあとで議員になった人もできる（`settle`）
- 答弁は質問ごとに1件、800字まで（質疑の答弁と同じ）。告知した議員が開催中にだけ書け、終了まで直せる。Turnstile は使わない（認証済みの議員が開催中に続けて書くため）
- 答弁が付いたら、質問を書いた人に通知する（質問ごとに1回。直したときは送らない）
- 通報は、質問と答弁のどちらにも、質疑・専門家の解説と同じ仕組みを使う（別々の3人の通報で一時的に非表示、登録から24時間たっていない人の通報は数えない、1日の通報の上限はほかの通報と合わせて数える）。答弁イベントには法案の提出者のような「関わった人」がないので、運営の画面で除くのは自分の書いたものだけ
- 見えなくなった質問は、答弁ごと、質問を書いた本人にだけ出す。見えなくなった質問には答弁を書けず、見えなくなった答弁は直せない（運営の判断を待つ）
- 運営の記録は「答弁イベントへの対応」として、法案の記録とは別の表 `toben_moderation_logs` に残す（ページ送りは `?toben=`）
