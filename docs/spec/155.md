# 公開ミラーの書き出し（決めたこと）

Issue #155。Normal（表は足さない）。仕様の正は [docs/spec.md](../spec.md) の「公開ミラー（GitHub）」と、Issue #147 の決めること22〜24。決めたこと A〜G と受入基準は Issue #155 にある。設定の手順は [docs/mirror.md](../mirror.md)。

ここには、実装で決めた読み方だけを書く。

## 入口

- `GET /mirror?after=<会期>`：書き出せる会期の一覧（`{ "sessions": ["2035-04", …] }`、古い順）。`after` があればそれより後だけ。形の違う `after` は 400
- `GET /mirror/<会期>`：その会期の IF世界の法令（`{ key, laws: [{ id, title, enacted, articles: [{ num, caption, paragraphs }] }] }`）。確定していない会期と形の違う会期は 404
- どちらも `Authorization: Bearer <MIRROR_TOKEN>` がないか違えば 401。ログインのセッションは見ない。`MIRROR_TOKEN` がない環境では、いつも 401
- 会期はカレンダーの月（`2035-04`）だけ。開発用の分の会期は書き出さない

## 確定した会期（D）の読み方

会期の処理は「結果の記録 → 可決法案の反映 → 現実の改正の取り込み」の順で、取り込みの終わった記録（`if_import_runs`）は反映が済んだあとにしかできない。そこで、取り込みの記録のある会期を古い順に見て、次をすべて満たす会期を確定とする。

- 会期が終わっている
- その会期より前に取り込んだことのある法令が、すべてその会期も取り込み済み（あとから委員会に足した法令は、足す前の会期を待たない）
- 確認中（`vote_reviews.status = 'open'`）の法案がない
- 可決して無効でない法案が、すべて反映されたか要調整になっている（確認中のあとで確定した法案は、次の処理で反映される）

**確定していない会期で止める**。そのあとの会期が確定していても返さない。前の会期のコミットを、あとから間に入れられないため。

## 時点（E）の読み方

IF世界の版の番号（`seq`）は処理した順なので、確認中のあとで確定した法案は、あとの会期の行より番号が大きくなる。そこで時点は番号ではなく会期で切る。その会期までに入った反映（`if_revisions.session_key`）と取り込み（`if_imports.session_key`）だけを、番号の順に重ねる。廃止と制定の新法も、その会期までに入ったものだけ。

- 法令の題名は、いまの現実の題名（IF世界の法令ページと同じ）。現実の版ごとの題名は DB に持っていないので、会期の時点の題名にはできない。IF世界の法案は現実の法令の題名を変えられない（題名を決めるのは制定の新法だけ）
- 対象の法令は委員会の対象の法令（`committee_laws`）と、IF世界で制定した新法

## Markdown の形

- 1行目は `# 第3条の2　（見出し）`。見出しのない条は `# 第3条の2` だけ
- 項と号は段落に分ける。2項からは番号付き（`2　…`）、号は漢数字（`一　…`）。法令ページの本文と同じ並び
- IF世界で削除した条は、本文が「削除」だけになる
- Markdown の記号として読まれる文字は `\` を付けて、文字のまま出す
- リポジトリの `README.md` には、架空の法令であること、どの会期の時点か、法令の一覧、ライセンス（CC BY 4.0）、クレジット、現実の法令の本文の出典（e-Gov法令検索）を書く
- 受け取った JSON の法令の ID と条の番号は、形を確かめてからパスにする

## バッチ

- `pnpm mirror --repo <ミラーのリポジトリ> --url <Worker の URL> [--no-push]`。トークンは環境変数 `MIRROR_TOKEN`
- コミットした `.osrippo-mirror` の次の会期から古い順に、会期ごとに中身を書き直して1コミットする。押すのは最後に1回。途中で失敗しても、コミットした会期の続きから進み、押せなかったコミットは次に流したときに押す
- 書く前に、ミラーのリポジトリかを確かめる（`.osrippo-mirror` をコミットしてあるか、まだコミットがなく `.git` のほかに何もない）。違えば何も消さずに止める（`--repo` の間違いで、ほかのリポジトリの中身を消さないように）。前に流したときの書きかけは捨ててから書く
- コミットの作者と、コミットした人は「オープンソース立法府 投稿者一同」（メールは `mirror@osrippo.invalid`）
