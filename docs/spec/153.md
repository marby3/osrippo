## パスの単語

仕様書（`docs/spec.md`）の「URLの設計」の表はこのリポジトリで書き換えないので、足した単語をここに記録する。

| 画面での言葉 | パス |
| --- | --- |
| 答弁（答弁イベント） | toben |
| 議員（議員ダッシュボード。#149） | giin |

- `/toben`：一覧（これから・開催中・終わった）
- `/toben/<番号>`：イベントのページ
- `/toben/kaku`：告知（議員だけ。ほかの人は 404）

## 決めたこと

- 時刻は、画面の日時の入力（`datetime-local`）を日本時間として読む
- 状態は、取り消し → 選挙で中止（開催の時間が登録された選挙の期間にかかる）→ 時刻 の順に決める。選挙で中止になったものは、選挙のあとも中止のまま
- 対象は、表示中の課題か、発議された法案。告知のあとで対象が非表示になったら、題名を出さない（「対象は表示していません」）
